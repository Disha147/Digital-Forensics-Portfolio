Project 01 – Windows Digital Forensics Investigation

Project Overview

This project documents a Windows Digital Forensics investigation conducted in a controlled lab environment. The investigation focuses on examining Windows Event Logs, analysing recorded activities, reconstructing an event timeline, and documenting findings.

Objectives

- Examine Windows Event Log evidence.
- Identify and analyse relevant system and security events.
- Document investigation observations.
- Reconstruct a timeline of relevant events.
- Perform evidence hash verification.
- Prepare a structured forensic investigation report.

Investigation Environment

- Operating System: Windows 10
- Investigation Type: Digital Forensics
- Evidence Sources: Windows Event Logs

Evidence Examined

The investigation covered the following Windows Event Log sources:

- Application.evtx
- Security.evtx
- System.evtx

Original evidence files are retained locally. They are not included in this public repository.
