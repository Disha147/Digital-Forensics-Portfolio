CASE ID: DF-001

CASE NAME: Suspicious Windows Activity Investigation

INVESTIGATOR: Disha Ghosh

SYSTEM: Windows 10

1. EXECUTIVE SUMMARY

This investigation examined selected Windows forensic artifacts to identify and document recorded system activity during the investigation period.

The examination identified credential-related activity and Windows Security events, including a Special Logon event and a successful Windows Logon event.

The findings document recorded operating system activity but do not independently establish the identity or intent of the individual physically operating the workstation.

2. INVESTIGATION PURPOSE

The purpose of this investigation was to examine a Windows workstation and identify recorded system activity using selected Windows forensic artifacts.

The investigation focused on understanding the timing and nature of recorded activity and determining what conclusions could reasonably be supported by the available evidence.

3. EVIDENCE EXAMINED

The investigation documentation identifies the following potential evidence categories:

- E001 – Windows Security Event Logs
- E002 – Windows Registry Artifacts
- E003 – Windows Prefetch Artifacts
- E004 – Browser Artifacts
- E005 – USB/Removable Device Artifacts

Evidence scope note: These categories should not be interpreted as confirmation that every artifact was collected or examined. Findings in this report are limited to the artifacts actually examined and documented.

4. METHODOLOGY

The investigation was performed in a controlled Windows 10 laboratory environment.

The examination process included:

1. Reviewing available Windows Security event logs.
2. Exporting relevant event-log evidence.
3. Calculating SHA-256 hashes for exported evidence files.
4. Examining selected Windows Security events.
5. Recording observations in separate event examination documents.
6. Organizing observed events chronologically in a timeline.
7. Correlating available observations during analysis.

5. KEY FINDINGS

The examined Windows Security logs contained recorded credential-related activity.

The following events were documented:

Finding 01 – Special Logon

- Event description: Special Logon
- Date: 16 September 2026
- Recorded time: Approximately 9:45:24 PM

Finding 02 – Successful Windows Logon

- Event ID: 4624
- Event description: Successful Windows Logon
- Date: 16 September 2026
- Recorded time: Approximately 9:59:12 PM

These events provide information about recorded Windows activity during the investigation period.

6. EVENT TIMELINE

The chronological event details are documented in:

"Timeline.txt.txt"

The timeline records the observed events, corresponding timestamps and evidence sources.

7. ANALYSIS

The examined Windows artifacts were reviewed and correlated to identify recorded system activity during the investigation period.

The available evidence indicates:

1. Windows Security logs recorded credential-related activity.
2. A Special Logon event was recorded during the investigation period.
3. A successful Windows Logon event was recorded at approximately 9:59 PM.
4. The examined events provide information about recorded Windows activity during the investigation period.

The evidence does not independently establish:

1. The identity of the person physically operating the computer.
2. The intent behind the recorded activity.
3. That any particular file or information was stolen or transferred.

8. INVESTIGATION LIMITATIONS

1. The investigation was performed in a controlled laboratory environment.
2. Individual Windows events provide only part of the overall activity.
3. The available evidence does not independently establish the identity of the physical computer operator.
4. Additional artifacts and independent correlation would be required to support stronger conclusions.

9. HASH VERIFICATION

SHA-256 hashes were calculated for the exported Windows Security, System and Application event-log files.

The recorded hash values and verification documentation are available in:

"Hash-Verification.txt.txt"

These hashes support integrity verification by allowing the calculated values to be compared against the recorded reference values.

10. CONCLUSION

The investigation identified and documented several recorded Windows Security events during the examination period.

The evidence supports the existence and timing of recorded Windows activity. However, the available evidence does not independently establish who was physically operating the computer or the intent behind the recorded activity.

The findings should therefore be interpreted within the limitations of the available laboratory evidence.

Further examination of additional digital artifacts would be necessary to establish stronger correlations and support more detailed conclusions.
